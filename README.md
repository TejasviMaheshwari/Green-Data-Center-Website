# Green Data Centers 🌿⚡

An informative, responsive website showcasing how modern digital infrastructure is transitioning toward environmental sustainability through renewable energy, advanced cooling, and intelligent power management.

---

## ✨ Features

- **Hero Video Background:** Immersive fullscreen video header highlighting eco-tech infrastructure[cite: 1, 2].
- **Clean Energy Insights:** Explains the role of solar, wind, and low-carbon electricity sources in powering high-demand computing[cite: 1].
- **Core Technology Grid:** Detailed cards explaining Liquid Cooling, Intelligent Airflow, AI-Powered Energy Management, and Waste Heat Recovery[cite: 1].
- **Environmental Impact Metrics:** Highlights 24/7 continuous demand, circularity, renewables, and Power Usage Effectiveness (PUE)[cite: 1].
- **Modern Responsive Design:** Crafted with an eco-tech color palette (deep forest green & lime accent), CSS Grid/Flexbox layouts, smooth scrolling, and mobile responsiveness[cite: 2].

---

## 🛠️ Built With

- **HTML5:** Semantic markup structure[cite: 1].
- **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, glassmorphic navigation, and media queries[cite: 2].
- **Typography:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [DM Sans](https://fonts.google.com/specimen/DM+Sans) via Google Fonts[cite: 2].
